# Portafolio de actividades

Esta carpeta contiene una página estática compatible con GitHub Pages:

- `index.html`: Actividad 4 (juego interactivo HTML) y Actividad 5 (investigación sobre Belbin).

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html` y `README.md` desde esta carpeta.
3. En el repositorio, abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/root`.
6. Presiona **Save** y espera la URL pública.

La Actividad 5 no incluye resultados inventados: la encuesta debe aplicarse a 17 compañeros y las entrevistas deben realizarse a Ana y Aaron antes de completar el análisis.
